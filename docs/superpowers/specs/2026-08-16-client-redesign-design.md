# 客户端排版样式重设计

**Goal:** 客户端窗口任意尺寸都不挤、不溢出、必保信息恒可见 — 三档布局 + 降级链, 保持毡布视觉基调。

**Architecture:** 布局数学抽成纯模块 `src/mahjong_ui/layout.py`(可单测的尺寸规划), `client.py` 的 `_paint` 只按规划消费绘制; paint 加异常兜底; 删除死代码(检测预览); 对外接口不变。

**用户确认的约束(2026-08-16):**
- 任意窗口尺寸都要好(用户频繁放大放小; 现状是窄了挤成一团、信息出界)
- 必保信息: 我的手牌 + 推荐牌、放铳风险行、对手听牌 + 牌河
- 可降级: 听牌组合小块优先省略
- 视觉风格: 保持毡布绿 + 象牙白麻将材质基调
- 自适应思路: 分档(窄/中/宽)+ 降级链

---

## 1. 三档布局(按窗口宽度 W 分档)

窗口最小尺寸 `setMinimumSize(360, 480)` — 低于此 Qt 自行钳制, 布局数学永远不处理更小的窗口。

### 窄档 W < 420(贴游戏旁的竖条)

```
┌─────────────────────┐
│ 右  [听23%] ████ +3 │  对手条 ×3(每家一行, 行高 30px):
│ 上  [听61%] ████ +5 │  方位标签(右/上/左, 窄档放弃方位映射改标签)
│ 左  [听8%]  ██      │  + 听牌徽章 + 副露牌块 + 牌河 mini 块 + 余数 +N
├─────────────────────┤
│  [推荐大牌块]         │  推荐区 110px: 牌块 + 一行理由(超出省略号)
│  打出 9饼 后 1 向听…  │
├─────────────────────┤
│ 我的手牌(大牌块行)     │  手牌牌块高 clamp(H×0.12, 40, 64)
│ 放铳 [候选小块+%]×N   │  放铳行 32px
│ (我的牌河 1 行 —      │  仅当剩余高度 ≥ 60px 才显示
│  空间富余才有)        │
└─────────────────────┘
```

### 中档 420 ≤ W < 700(现行"微型牌桌"结构保留)

- `m = clamp(W // 30, 6, 16)` 边距;`top_h = clamp(H×0.14, 34, 64)` 对家横条;`side_w = clamp(W×0.21, 84, 150)` 左右竖条;`mid_h = clamp(H×0.38, 160, 260)` 中部;我的区 = 剩余
- 对家横条、左右竖条、中央推荐、底部我的区 — 方位映射即信息(不画"对家/左家"标签)
- 修复现有挤压问题: 听牌概率改为徽章(参与布局计算), 不再用固定 42px 偏移; 听牌组合、图例、副露标签全部按降级链参与布局

### 宽档 W ≥ 700(放大牌桌, 全信息)

- 同中档结构, 比例放大: `top_h = H×0.16`、`side_w = W×0.23`、中央字体 14
- 听牌组合、图例、副露"副露"标签、我的牌河全部显示; 推荐理由完整多行

**档内原则:** 每档内元素尺寸仍随 W/H 比例缩放; 档切换只发生在阈值处。

## 2. 降级链(空间不足时按固定顺序隐藏, 绝不溢出/裁剪)

| 序 | 元素 | 降级方式 |
|---|---|---|
| 1 | 听牌组合小块 | 省略(用户确认可丢) |
| 2 | 颜色图例 | 省略(仅中/宽档有; W < 560 不画) |
| 3 | 副露带"副露"文字标签 | 省略文字, 牌块保留 |
| 4 | 我的牌河 | 窄档仅余高 ≥60px 显示; 中/宽档缩至 1 行, 再不够省略 |
| 5 | 对手牌河明细 | 只画放得下的张数, 末尾 `+N` 余数徽章(张数信息不丢) |
| 6 | 推荐理由文字 | 缩成一行, 超出省略号(牌块永不缩没) |

**永不降级:** 我的手牌、推荐牌、放铳风险行、三家听牌%徽章、副露牌块。

**听牌组合显示门槛(2026-08-16 用户实测修正):** 听牌概率 < 10% 时不画听牌组合 — 开局 2% 先验只有 ~8 个听牌粒子, top3 等待牌是纯噪声("还没出牌就有听牌组合")。概率 ≥10% 才显示。

**副露 vs 听牌两行堆叠(2026-08-16 用户实测修正):** 左右家窄竖条里听牌徽章+副露牌块物理放不下同一行(两个都永不降级) — 有副露的区域:副露带占满顶行,听牌徽章+听牌组合单独在带下一行;无副露的区域:听牌徽章在顶行。牌面流在两者之下。

**显示容量统一走纯函数** `fit_count(space, tile_w, gap, n) -> (可见张数, 余数)` — 所有"放得下几张画几张"处共用, 禁止各处手写截断。

## 3. 视觉样式(毡布基调不变)

- 保留现有色板: 毡布绿 `_FELT`、象牙白 `_IVORY`、万红 `_WAN`、饼蓝 `_BING`、条绿 `_TIAO`、风黑 `_WIND`、米白 `_TEXT`、弱化 `_DIM`、警示橙 `_WARN`
- **听牌概率 = 圆角徽章(pill)** 替代角落裸文字: `<30%` 弱色 / `30-60%` 橙 / `≥60%` 红(沿用现有阈值)。徽章宽按文字预算, 参与布局
- **分区卡片化**: 四家区域与推荐区同规格圆角卡片(比背景浅一档的毡布色 + 统一描边)
- **窄档对手条**: 方位标签 + 听牌徽章 + 副露牌块(16×22) + 牌河 mini 块 + 余数徽章
- **字号分档**: 窄 8-9 / 中 8-11 / 宽 10-14, 统一 Microsoft YaHei; 所有文字画进预算矩形, 超长截断
- **推荐区**: 宽档推荐牌块可达 72px 高 + 一行大字理由; "你已听牌"绿色标题保留
- 待定牌半透明(0.55)、暗牌位、副露真实牌块语义全部保留, 只重做尺寸计算

## 4. 健壮性与结构

- **paint 兜底**(审查③): `_paint` 包 try/except — 异常时画毡布底 + "显示异常"提示; 同一异常 5 秒内只记一次日志(避免每帧刷屏)
- **布局纯函数**: 新模块 `src/mahjong_ui/layout.py` 提供 `plan_layout(w, h) -> LayoutPlan`, 含: tier、各区域 rect、降级标志、各流显示容量;`client.py` 只消费 LayoutPlan, 不自行算布局
- **删除死代码**: `set_preview`/`_draw_preview`/`_preview`/`_preview_wh` 全项目无调用(实测 grep 确认), 移除
- **接口不变**: `MahjongClient.update(advice, boxes, provisional)`、`set_status` 签名不动; `run_assistant.py` 零改动
- **错误处理**: LayoutPlan 对任意 w/h 不抛异常(输入被 Qt 最小尺寸钳制 + 内部 clamp 兜底)

## 5. 测试

- 新 `tests/test_ui/test_layout.py`: 扫尺寸 360×480 → 2000×1200(步进 ~80px)断言:
  - 所有区域 rect 不越界、宽高非负
  - 相邻区域不重叠(对手区/推荐区/我的区两两)
  - 必保元素恒有正尺寸(手牌行、放铳行、对手条、推荐牌块)
  - tier 判定与阈值一致; 降级标志随空间单调(空间增大 → 降级不增加)
- 现有 342 测试保持全绿
