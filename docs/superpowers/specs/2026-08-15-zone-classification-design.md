# 三区身份重设计:事件推断为主(手牌/副露/牌河)

> 状态: 已确认设计(2026-08-15 头脑风暴三节全过)。实现走 writing-plans。

## 1. 目标

替换 v4 现行的"DBSCAN 形状特征分类"三区区分方案。副露身份不再依赖
"把三张牌看对" — 改为**事件推断为主**(牌河消失 + 手牌数台阶 + 行动权),
位置区域做确认层,视觉检测降级为显示/填充通道。

## 2. 背景:现行方案的失败模式(四局真实日志 + settle.png 复现)

| # | 失败 | 现行机制为何失效 |
|---|---|---|
| 1 | 手牌塌陷时牌河行/副露行被当成手牌 | 手牌判据是相对的(横排+尺寸≥全局平均×0.75+最靠下),真手牌一消失,牌河行全满足 |
| 2 | 对手手牌列被确认成假副露([8,24,25,26]→"杠") | right_meld 框压在右家手牌列上;区域内 2-4 张紧邻就确认 |
| 3 | 2 张组确认副露([0,0]、[7,8]、[31,31]、[8,25]) | _check_meld 确认门槛 ≥2 张 |
| 4 | 字牌假副露([28,30,30] 南南北) | 无组合合法性校验 |
| 5 | 手牌长时右端伸进 my_meld 区域 | 形状聚类不知区域边界 |
| 6 | 手牌检测在副露动作前后塌陷,不再恢复 | 检测侧根因待诊断(band_dets 探针已上线) |

已有修复保留:手牌带锚定(带外聚类拒绝,宁可空不可错)、牌河区域门禁、
局中闩锁、跨局重置。

## 3. 设计原则

1. **事件推断为主**:副露的可靠信号是副作用(牌河最新一张消失、手牌数
   掉 2/3、副露者马上出牌),不是"看到那三张牌"。
2. **位置确认**:手牌带、牌河区域(已上线)作为确认层保留。
3. **检测显示**:视觉副露检测降级为显示/填充通道,检测不到不致命。
4. **退化原则**:每个机制定义检测塌陷时的行为 — 内容降级为 unknown,
   **而不是错**。

## 4. 架构

下游(解码器/状态投影/客户端)接口不变,只认 MeldFormed/TileClaimed/
TileAppeared/HandChanged。变化只在**副露事件怎么产生**。

### 4.1 RiverWatcher — 牌河消失检测器

- 每河状态 = 该河最近一次 TileAppeared 的 (tile, cx, cy)(落定后开始盯)。
- 在场判定:该 tile 出现在原位置半径 1.5×框宽内。
- 连续缺失 ≥15 帧(≈2s @7fps)且**同河其他牌还在** → `TileVanished{tile,
  river, appeared_eid}`(新事件类型,加进 events.py)。
- 整河检测塌(抽风)不算消失;飞牌遮挡的 1-2 帧缺失被阈值吸收。
- 区域重映射后位置随新区域走(运行器重播种时重映射)。

### 4.2 HandTracker — 我的手牌兜底 + 台阶签名

- 健康判定:带内手牌 ≥5 张且去抖计数连续 ≥5 帧落在 8-14。
- 检测健康时:手牌 = 检测(现行为)。
- 检测塌陷时接管:手牌 = 最后已知 − 之后我的打出(出现在 my_river 区域
  的 TileAppeared)− 我的副露扣除;摸进的新牌 = 未知槽(显示暗牌位)。
- **台阶签名**:5 秒滑动窗口内计数模态从 12-14 带 → 9-11 带(掉 2)/
  8-10 带(掉 3)且新模态停留 ≥2 秒 = 副露签名。抽风是振荡不落脚,
  不构成台阶。

### 4.3 MeldInferrer — 副露推断器(核心)

状态机:候选 → 等证据 → 确认/丢弃。

- **我的副露**:TileVanished(X) ±2 秒内我的台阶 -2/-3 → 我副露;内容 =
  X + 手牌前后差的两张/三张(前 = vanish 前 2 秒内的最后稳定手牌,
  后 = 台阶落地后 2 秒内的首个稳定手牌;检测健康时全知,塌陷时
  X + 2 未知)。
- **我的副露(快碰, 2026-08-15 补充)**:被碰牌太快从未进牌河(无消失)
  时,台阶独立确认 — 摸打只 ±1,手牌掉 2/3 只有副露一种可能;内容 =
  手牌差(合法性校验:碰=同牌对、吃=同花 ±2、杠=同牌×3,不成副露
  不确认);被碰牌由最近同类打出配对(吃=顺子补第三张,暗杠无被碰)。
  消失候选在等/已确认过时不重复发。
- **对手副露**:TileVanished(X) 后 2~5 秒内**第一家打出的牌** → 那家副露
  (行动权在副露者);内容 = X + 2 未知。
- **对手副露内容推断(2026-08-15 补充)**:内容未知时用牌池(剩余未知
  张数)收窄 — 碰需要池中 ≥2 张 X,吃需要顺子其余两张各 ≥1。唯一解
  = 确定(扣池全扣 + 显示真实组合);多解 = 歧义(只扣被碰牌,显示
  被碰牌 + 暗块)。扣池(M3)与显示两处消费同一函数,结论一致。
- **杠**:我的台阶 -3 → 明杠(X + 3 张差);对手看不到手牌数,按碰处理
  (推断上仅扣池差 1 张);视觉检测到 4 张组时修正。
- **吃/碰不分**(对手):扣池、手牌数、解码全部相同,仅显示样式不同;
  视觉检测到合法组时再定。
- **超时**:5 秒无台阶无出牌 → 降级等合法视觉组兜底;再 3 秒无 → 丢弃。
  **宁可缺事件,不发假事件。**
- **视觉确认/填充**:候选期内合法视觉组出现 → 确认并填充对手的 2 张
  未知牌;完全没消失证据时,合法视觉组(≥3 张 + 合法组合 + 持续 ≥5 帧)
  兜底确认。
- 连续副露:多个候选按时间序最近原则配对。
- TileClaimed 的 claimed 直接取 TileVanished.appeared_eid — 现有
  _CLAIM_MAX_AGE 10 秒兜底配对被取代。

### 4.4 视觉副露检测降级(现有区域路径加固)

- 确认门槛:≥3 张 + 组合合法 + 持续 ≥5 帧。
- 组合合法:碰=同牌×3、吃=同花连号(0-26)、杠=同牌×4 — 南南北类假副露
  从此进不来。
- 只做两件事:① 给有消失证据的副露填充/确认;② 消失信号漏掉时兜底。
- 暗杠/加杠(无被碰牌):仅走视觉合法组通道,为已知限制。

### 4.5 解码器唯一改动

消费 TileVanished → 把被碰走的那张从丢弃者牌河投影摘掉(顺手修
"被碰走的牌还显示在丢弃者牌河"显示 bug)。其余不动。

## 5. 数据流

```
dets → ① cluster_dets(手牌带锚定, 已上线) → 手牌簇/视觉副露组/牌河簇
     → ② RiverWatcher: 各河最新牌在场检查 → TileVanished
     → ③ HandTracker: 兜底手牌 + 台阶签名
     → ④ MeldInferrer: 信号组合 → MeldFormed/TileClaimed
     → 事件输出(下游零改动)
```

MeldFormed 无视觉组时:bbox = 该家副露区域中心(我的副露区/对手副露区),
显示层用 tiles 画真实牌块 — 我的副露内容已知(X + 手牌差),对手 = X +
2 暗块(视觉填充后画真实牌)。

## 6. 错误处理/退化矩阵

| 故障 | 行为 |
|---|---|
| 消失信号漏掉(被碰牌从没进过牌河检测) | 合法视觉组兜底;否则无事件 — 少记一张,不致命 |
| 副露者 5 秒识别不出(出牌漏检) | 候选丢弃,不发假事件 |
| 台阶+消失成立但手牌差算不出(恰好塌陷) | 副露确认(双信号),内容降级 X+2 未知 |
| 视觉假阳性(南南北类) | 合法性校验直接拒绝 |
| 手牌差补全被另一次副露/抽风污染(2026-08-16 实测: 被碰 17 + 第二次副露差 (20,21) → 假吃 (17,20,21)) | `meld_valid` 校验被碰牌+手牌差, 不合法不采用 → 超宽限按未知 (X,) 发射, 显示暗牌位 |
| 视觉组合法性(双保险) | MeldInferrer 对提取器产出的视觉组再验 `meld_valid`(提取器已筛, 推断器不信任) |
| 整河检测抽风 | "同河其他牌还在"条件挡住,不发消失 |
| 窗口移动/区域重播种 | 消失位置随区域重映射;手牌带重锚(已上线) |
